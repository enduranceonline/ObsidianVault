# Decisiones tecnológicas

## Laboratorio SIEM

---

## 1. Introducción

Este apartado recoge las decisiones tecnológicas adoptadas para el desarrollo del frontend del Laboratorio SIEM. El objetivo no es detallar la implementación, sino justificar la elección de las tecnologías utilizadas en función del alcance, los objetivos y el contexto académico del proyecto.

---

## 2. Tecnologías seleccionadas

Para la implementación del frontend se utilizarán tecnologías web estándar:

- **HTML** para la estructura de la interfaz.
    
- **CSS** para el diseño y la presentación visual.
    
- **JavaScript** para la interacción con el backend y la gestión dinámica de los datos.
    

Estas tecnologías permiten desarrollar una interfaz funcional y comprensible sin introducir dependencias externas ni complejidad adicional.

---

## 3. Justificación de la elección

La elección de tecnologías web estándar responde a los siguientes criterios:

- Adecuación al nivel del ciclo formativo.
    
- Facilidad de comprensión y mantenimiento.
    
- Ausencia de dependencias innecesarias.
    
- Enfoque en la lógica del sistema, no en el framework.
    

El uso de frameworks o librerías avanzadas no aporta valor adicional al objetivo principal del proyecto, que es comprender el funcionamiento de un sistema SIEM desde el punto de vista arquitectónico.

---

## 4. Tecnologías descartadas

No se utilizan frameworks frontend avanzados (como React, Angular o Vue) ni librerías de visualización complejas, ya que:

- Introducen complejidad adicional.
    
- Desplazan el foco del proyecto hacia el frontend.
    
- No son necesarias para cumplir los objetivos funcionales definidos.
    

---

## 5. Alcance de la implementación frontend

El frontend se implementa como una interfaz ligera orientada a:

- Consultar información.
    
- Visualizar alertas y eventos.
    
- Interactuar con el backend mediante peticiones HTTP.
    

No se persigue desarrollar una aplicación frontend compleja ni altamente interactiva.
